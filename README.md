# Bringle SMG2 Mods
<img width="1920" height="1080" alt="Bringle thumnail" src="https://github.com/user-attachments/assets/edbf7991-0ae0-4976-ac70-f41d8a1b0fe9" />

This repo contains the SMG2 mod that [Bringle](https://www.youtube.com/@BringlesCan) played on his live stream with the following features:
- Cosmic Clones anywhere (by me)
- CometTimerObj (by Evanbowl)
- Death Counter (by VTXG)
- Custom Power Star Colors (by Myron Dragon and Evanbowl)
- Gooner Guy NPC (by me)
- Red Star (by Aurum)
- Roshambo/Rock Paper Scissors (by me)

If you want to see how this works and how I made it, you can watch my video here:
https://youtu.be/qOQIVLE83Xs

## Play it yourself!
You can download the zip [here](https://github.com/bavario-lginc/Bringle-SMG2-Mods/releases/tag/release).

On Dolphin: Right-click your copy of Super Mario Galaxy 2, click `Start with Riivolution patches...` and select the .xml file in the `riivolution` folder that works for your region.

On a real Wii (with Riivolution installed): Simply copy both folders onto your SD Card and then apply the mod in Riivolution.
